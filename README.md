# DRBiN Code (Reproducibility Package)

This repository provides the implementation used in the experimental evaluation of the proposed DRBiN framework.

## Requirements

The code has been tested with the following environment:

- Python 3.8.18  
- PyTorch 2.4.1 (CUDA 12.1)  
- torchvision 0.19.1  
- torchaudio 2.4.1  
- mmcv-full 1.4.6
